# iOS on Pixel: cubs port

An experimental iOS 16.5 port for the Pixel 11 (cubs), with the longer-term aim of helping ports to related Pixel devices. This project is under active development and is not yet a ready-to-use installation.

This repository is being prepared. Source code, documentation, and complete third-party notices have not yet been migrated here. Hardware support and compatibility with other devices are not established by this page.
